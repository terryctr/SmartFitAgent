## 一、环境要求

## 二、标准启动（H2 内存数据库 + Mock AI）

无需任何额外配置，开箱即用：

```bash
cd SmartStudyAgent
mvn spring-boot:run
```

启动成功后控制台输出：

```
SmartFitAgent 已启动: http://127.0.0.1:8080
```

浏览器打开 <http://localhost:8080> 即可使用。

---

## 三、接入 DeepSeek 真实 AI

**方式一：直接修改配置文件（推荐）**

编辑 `src/main/resources/application.yml`，修改以下两行：

```yaml
ai:
  provider: ${AI_PROVIDER:deepseek}   # 将 mock 改为 deepseek
  deepseek:
    api-key: sk-你的DeepSeek密钥       # 填入真实 Key
```

保存后重启，控制台出现以下日志即接入成功：

```
INFO  AppConfig - 使用 DeepSeek 策略: model=deepseek-chat
INFO  AppConfig - AI 核心客户端: deepseek:deepseek-chat
```

**方式二：环境变量（不修改代码）**

```bash
DEEPSEEK_API_KEY=sk-你的密钥 AI_PROVIDER=deepseek mvn spring-boot:run
```

## 五、切换 MySQL 数据库（可选）

1. 执行建库脚本：

```bash
mysql -uroot -p < src/main/resources/schema.sql
```

2. 修改 `application.yml`：

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/smartfitagent
    username: root
    password: 你的密码
    driver-class-name: com.mysql.cj.jdbc.Driver
```

3. 启动时添加环境变量：

```bash
DB_MODE=mysql mvn spring-boot:run
```

## 六、端口冲突处理

若 8080 端口被占用：

```bash
# 查看占用进程
lsof -ti :8080

# 终止占用进程
kill $(lsof -ti :8080)

# 或换用其他端口
mvn spring-boot:run -Dspring-boot.run.arguments=--server.port=8081
```
