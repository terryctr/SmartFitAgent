# SmartFitAgent — 软件功能手册

## 产品简介

SmartFitAgent 是一款基于 Spring Boot + MVC 架构的 AI 智能健身管理平台。它集成了通义千问（Qwen）、DeepSeek、Kimi 三大大语言模型 API，通过多阶段 AI 处理管道（意图识别→提示词增强→上下文注入→安全过滤→后处理），将用户的健身数据与 AI 建议深度融合，提供个性化的训练、营养、恢复指导。

## 核心功能详细说明

### 1. AI 教练（多模型智能对话）

**位置**：`/pages/tutor.html`

**功能描述**：
- 支持选择 9 种专业 AI Agent 角色：
  - **通用教练**：综合健身建议
  - **营养 Agent**：膳食方案、宏量素计算
  - **恢复 Agent**：训练后恢复、肌肉修复
  - **心态 Agent**：运动心理、坚持动力
  - **进度 Agent**：进步分析、数据解读
  - **挑战 Agent**：挑战推荐、难度匹配
  - **计划 Agent**：训练周期规划
  - **健康 Agent**：健康知识问答
  - **体能测试 Agent**：体能水平评估
- AI 处理管道对用户输入进行**5阶段增强**：
  1. **意图识别**：分析用户意图（训练/营养/减重/恢复/健康等9类）
  2. **提示词增强**：添加时间戳、关键词标注、格式化指引
  3. **上下文注入**：注入用户个人档案、BMI、训练历史
  4. **安全过滤**：屏蔽危险建议（违禁药物、极端节食等）
  5. **响应后处理**：提取行动建议、添加必要免责声明
- 支持 **SSE 流式输出**，文字逐字显示
- 支持切换 Qwen / DeepSeek / Kimi 三个模型提供商

**操作步骤**：
1. 选择 Agent 类型（右上角下拉菜单）
2. 在输入框中输入问题
3. 点击「发送」或按 Enter
4. AI 回复会实时流式显示
5. 点击「清空对话」重置上下文

### 2. 训练日志

**位置**：`/pages/workout.html`

**功能描述**：
- 录入训练动作（类型、名称、组数、次数、重量、时长）
- **自动计算消耗热量**（基于运动类型和时长，内置 35+ 运动的代谢当量）
- 实时统计：总训练次数、总分钟数、总热量消耗、连续打卡天数
- AI 每日训练推荐（根据个人计划生成）
- 历史记录表格（含类型徽章、热量标签）

**API 端点**：
```
POST /api/workout/logs     记录训练
GET  /api/workout/logs     获取历史
GET  /api/workout/stats    获取统计
GET  /api/workout/recommend AI推荐今日训练
```

### 3. 营养追踪

**位置**：`/pages/nutrition.html`

**功能描述**：
- 按餐次（早/午/晚/加餐）记录食物摄入
- **100+ 种常见食物热量数据库**，支持搜索自动补全
- 实时宏量素进度条（蛋白质 / 碳水化合物 / 脂肪 / 热量）
- 按餐次分类展示每日饮食记录
- 食物数据库按类别筛选（蛋白质食物 / 主食 / 蔬菜 / 水果）
- AI 营养 Agent 可分析当日摄入并给出优化建议

**宏量素计算逻辑**：
- 减脂期（CUT）：蛋白质 2.0g/kg，碳水 2.5g/kg，脂肪 0.8g/kg
- 保持期（MAINTAIN）：蛋白质 1.6g/kg，碳水 3.5g/kg，脂肪 1.0g/kg
- 增肌期（BULK）：蛋白质 1.8g/kg，碳水 5.0g/kg，脂肪 1.2g/kg

### 4. 身体测量追踪

**位置**：`/pages/measurements.html`

**功能描述**：
- 记录体重、体脂率、肌肉量及 7 个身体围度（胸/腰/臀/手臂/大腿/小腿/颈围）
- 与上次测量对比，显示变化趋势（↑↓ 带颜色标注）
- BMI 实时计算（中国标准：18.5–23.9 为正常）
- **腰臀比（WHR）**分析
- **体型评估**：脂肪量、瘦体重分解
- 历史数据表格，支持时间排序

### 6. 成就系统

**位置**：`/pages/achievements.html`

**功能描述**：
- 14+ 种成就徽章，覆盖连续打卡、训练量、营养、目标、挑战、特殊等类别
- 积分系统（每获得成就得 30~400 分不等）
- 用户等级（每 500 分升一级）
- 成就按类别筛选、解锁状态展示
- 点击「检查新成就」触发后端实时评估
- 稀有徽章统计（积分 ≥200 的高价值成就）

**成就解锁条件示例**：

| 成就名 | 条件 | 积分 |
|-------|------|------|
| 三日不辍 | 连续3天训练记录 | 30 |
| 月度冠军 | 连续30天训练记录 | 300 |
| 健康体重 | BMI 进入 18.5–24 范围 | 200 |
| 完美一周 | 一周5训练+7天饮食记录 | 400 |
| 挑战完成 | 成功完成一个挑战 | 100 |

### 7. 睡眠追踪

**位置**：`/pages/sleep.html`

**功能描述**：
- 记录入睡/起床时间，自动计算时长

- 记录夜间醒来次数和入睡耗时
- 标记干扰因素（压力/咖啡因/晚间训练/光线/噪音）

- 睡眠阶段分布估算（深睡/浅睡/REM/清醒）
- AI 睡眠顾问：分析数据并给出个性化改善建议
- 科学睡眠建议卡片（6条实证建议）

## AI 处理流程说明

用户输入消息后，AI 管道按以下顺序处理：

```
用户输入
    ↓
[IntentDetectionStep]
  分析意图类别（9类）
  提取数字实体（体重/热量/天数等）
    ↓
[PromptEnrichmentStep]
  添加意图标签
  注入当前日期时间
  添加关键词注释
  追加回复格式指引
    ↓
[ContextInjectionStep]
  注入用户档案（身高/体重/BMI/目标）
  注入意图相关系统提示
  添加安全免责声明
    ↓
[SafetyFilterStep]
  检测违禁内容（违禁药物、极端节食等）
  检测极端热量设定（<600kcal）
  短路非法请求
    ↓
[调用 LLM API]
  三选一：Qwen / DeepSeek / Kimi
    ↓
[ResponsePostProcessStep]
  提取行动建议（编号列表）
  添加运动损伤免责声明
  检测极端热量警告
    ↓
返回增强后的 AI 回复
```
